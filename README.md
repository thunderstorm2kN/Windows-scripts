# Windows Scripts

A collection of useful scripts for Windows 11 that I use for system management and automation.

## Overview

This repository contains PowerShell and batch scripts designed to enhance Windows 11 functionality and streamline common tasks. These scripts are tailored for personal use and system administration.

## Scripts Included

### 1. Windows 11 Update Scripts
Automated scripts that guide users to Windows 11 updates and software management.
- **Settings Update Script**: Redirects users to the Windows Settings app for system updates
- **Microsoft Store Script**: Directs users to the Microsoft Store for app updates and new applications

### 2. RGB Hardware Management Script
A script for managing RGB lighting on compatible hardware through Windows 11's Dynamic Lighting feature.
- Control RGB devices integrated with Dynamic Lighting from Settings
- Automate lighting profiles based on system state or user preferences

### 3. Wake-on-LAN (WOL) Script
A utility script to remotely wake up PCs or servers on your local network using Wake-on-LAN technology.
- Start up Windows machines remotely
- Wake Ubuntu servers and other networked devices (e.g., Ubuntu Server)
- Useful for remote system management without physical access

## Requirements

- Windows 11
- PowerShell (for script execution)
- Appropriate network permissions for WOL functionality
- Compatible hardware for RGB management

## Usage

Each script can be run from PowerShell. Refer to individual script documentation for specific usage instructions.
